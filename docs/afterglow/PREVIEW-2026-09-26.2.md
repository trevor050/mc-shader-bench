# Afterglow Preview 2026-09-26.2

This preview is a three-file bundle for Minecraft Java Edition 26.2. Add the shader archive and the two client mods to the same Fabric instance. The End ambience and GUI queue mitigations are optional; Afterglow itself works without either mod.

## Requirements

| Component | Requirement |
| --- | --- |
| Minecraft | Java Edition 26.2 |
| Java | Java 25 or newer |
| Mod loader | Fabric Loader 0.19.5 or newer |
| Fabric API | Fabric API for Minecraft 26.2 (the local release build used 0.161.0+26.2) |
| Shader loader | Iris 1.11.4 |
| Renderer | Sodium 0.9.2, installed with the verified Iris stack |
| Optional distant terrain | Distant Horizons 3.3.2 |
| Graphics | OpenGL 4.3 or newer |

The local release checks used Windows 11 and an NVIDIA RTX 4070. Local captures, including individual text-entry keys and command completion, did not reproduce the severe frame collapse. End-to-end keypress-to-display latency was not measured. They do not qualify the reported RTX 2060 Super symptom, so the optional mitigation is not presented as a confirmed fix for that system.

## Bundle files

The outer bundle is `Afterglow-preview-2026-09-26.2-bundle.zip`. It contains the shader in `shaderpacks/` and both optional JARs in `optional-mods/`. Move a JAR into your instance's `mods` folder only to enable that feature. Do not put the outer bundle ZIP in the shader picker. Contents:

| File | Install location | Required? |
| --- | --- | --- |
| `Afterglow-preview-2026-09-26.2.zip` | Instance `shaderpacks` folder; keep the file zipped | Yes |
| `claudebench-ambience-0.1.0.jar` | Instance `mods` folder | No, adds End storm ambience |
| `afterglow-client-fixes-0.1.0-preview.1.jar` | Instance `mods` folder | No, enables the optional GUI queue mitigation |

The inner shader archive must retain the exact name `Afterglow-preview-2026-09-26.2.zip`. The GUI addon uses that identity to decide when its mitigation applies. The bundle's outer filename does not affect this check.

## Install

1. Create or select a Fabric instance for Minecraft 26.2. Make sure it uses Java 25 or newer and has Fabric API installed.
2. Install Iris 1.11.4. The verified stack uses Sodium 0.9.2. Add Distant Horizons 3.3.2 only if you want distant terrain.
3. Open the instance's folders. Copy `Afterglow-preview-2026-09-26.2.zip` into `shaderpacks` and leave it zipped.
4. To add the End ambience, copy `claudebench-ambience-0.1.0.jar` into `mods`. It requires Fabric API; AmbientSounds is optional and adds extra wind and storm recordings.
5. To add the GUI queue mitigation, copy `afterglow-client-fixes-0.1.0-preview.1.jar` into `mods`. It is a separate client mod and does not change shader quality settings.
6. Launch the instance. In **Options → Video Settings → Shader Packs**, select the new Afterglow preview from the list and apply it. The first load may pause while Iris compiles the shaders.

Restart Minecraft after adding or removing either mod.

## Optional GUI queue mitigation

The GUI addon is independent of the End ambience mod. With its default setting enabled, it acts only when all three conditions are true: a world is loaded, an in-world screen is open, and Iris reports an active shader pack whose identity exactly matches this preview's allowlist. It waits for the just-submitted GPU frame fence for up to 30 ms per eligible submission. If the fence completes, this reduces queued GPU work; it may also lower GUI frame throughput while the screen is open. There is no global FPS cap, and closed-screen world rendering adds no fence wait.

This is a reversible queue-depth mitigation, not a guaranteed limit on total stalls. If the 30 ms wait times out, Minecraft can still wait on that same unfinished fence during a later submission. The preview has not been qualified as a fix for the reported RTX 2060 Super issue.

In a world, use these client commands:

- `/afterglowfix status` reports whether the guard is enabled, why it is or is not active, and its completed and timed-out wait counts.
- `/afterglowfix off` disables the extra wait and saves the choice.
- `/afterglowfix on` enables it again and saves the choice.

The setting is stored in `config/afterglow-client-fixes.json`. The guard skips renamed archives and unlisted shader packs. Keep the shader archive's exact filename when installing it.

## Remove

Select **None** or another shader pack, then remove `Afterglow-preview-2026-09-26.2.zip` from `shaderpacks` to remove Afterglow. Delete either optional jar from `mods` to remove its feature. Removing the GUI addon restores Minecraft's default submission behavior.
