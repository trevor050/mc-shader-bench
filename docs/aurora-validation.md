# Offline aurora validation

`py shaderpack/tools/verify_aurora.py` compiles and renders the aurora GLSL directly through a standalone OpenGL 4.3 context. It extracts the current aurora section from `shaderpack/shaders/lib/night.glsl`, together with the live `hash12` and `valueNoise` implementations from `common.glsl`. It does not launch Minecraft or reproduce the deferred sky, cloud, rain, exposure, or final tonemap pipeline.

The default run writes a horizon-centered north view, a north view pitched up 30 degrees, a zenith view, and an equirectangular panorama at five shader-time samples to `work/aurora/`, each as aurora-only and Milky-Way-plus-aurora. It uses the current `AURORA_MODE`, `AURORA_BRIGHTNESS`, `MILKYWAY_BRIGHTNESS`, and `MILKYWAY_SATURATION` values. For the sky render it supplies `inSnowy=1`, `moonPhase=0` (full moon), a zero rain level, midnight sun height, and camera `(0,64,0)`. `worldDay` defaults to the first random-active day found in the first 4096-day GPU sample (day 6 for the checked mode-3 source). Shader time values are seconds. PNGs use a simple shared display curve; PFM and NPY preserve raw linear values. `metrics.json` records the source hash, GPU identity, finite/nonnegative checks, luminance percentiles, temporal image deltas, and the texture reference.

The Milky Way preview follows the real `nightSky()` equatorial mapping for a fixed midnight sun, then applies the texture shaping, saturation, brightness, dark-sky gate, and atmospheric extinction from `stars.glsl`. It leaves out the procedural grain/wisp overlay, star catalogue, moon, sky atmosphere, clouds, and the rest of deferred rendering. The reference metrics decode `milkyway.dat` as RGBA16 UNORM per `shaders.properties`, then apply the texture shaping and `MILKYWAY_BRIGHTNESS` scale. These values are useful radiance references, not perceptual equivalence: the real scene also includes exposure, stars, moonlight, atmosphere, and tonemapping.

When both `auroraNightRoll(int)` and `auroraNightActive(int)` are present in the aurora source, the script evaluates them on the GPU over 4096 consecutive day values, reports event frequency, roll bounds, and consecutive-night pairs. It includes day -1 as the preceding-day check. This verifies the shader implementation's deterministic selection properties over that sample; it does not establish a visual-quality threshold.

Dependencies (install once if missing):

```powershell
py -m pip install moderngl glcontext numpy pillow
```

Optional arguments include `--width`, `--height`, `--day`, `--time`, `--output`, and `--backend wgl`. A driver without standalone OpenGL 4.3 support cannot run this harness; the script reports context creation or shader compilation errors directly.

Run `py shaderpack/tools/verify_aurora.py --gate-matrix` to compile the live aurora code with each of the four `AURORA_MODE` values and test 48 combinations per mode: active/inactive day, snowy/non-snowy, moon phase 0/4, rain 0/0.5/1, and night/day sun height. The report includes the expected and actual visibility for each case plus repeated active-day roll/activity outputs, which must be stable.

For a bounded GPU cost estimate without image readback, run `py shaderpack/tools/verify_aurora.py --timing`. It times a reused fullscreen program, VAO, and single-channel target at 3440×1369 with three warmups and eight measured frames for each of four conditions: eligible night, daytime visibility gate, negative snow/full-moon event inputs, and a baseline that skips aurora evaluation. `timing.json` contains raw samples, median, p10, p90, and max. Override dimensions or sample count with `--timing-width`, `--timing-height`, and `--timing-frames`. On the RTX 4070 source hash `437959f5`, a paused-game 24-frame run measured 1.945 ms median, 5.667 ms p90, and 6.032 ms max for the eligible-night draw; daytime gate median was 0.0348 ms and the no-aurora baseline median was 0.0287 ms. The active result was bimodal, so this is not a clean sub-3 ms pass. That benchmark predates the final source hash `5933348c`: the geometry and integrator remain the same, but the final source removes fine/detail noise, reducing the noise evaluations from five to three. Treat the timing as historical evidence, not a final-source timing receipt. These are standalone GPU shader timings, not Minecraft frame times or FPS, and can shift with GPU scheduling and clocks.

Final source hash `5933348c9e7858ad5f95fbc0ad8add7076721b6d109f10354f14d3d305cbe878` passed all 192 mode-gate cases and repeated selector stability for modes 1–4. On the RTX 4070, 640×360 north-up30 samples at `t=0, 0.1, 0.2, 3599.9, 3600` were all finite and nonnegative; the 3599.9-to-3600 mean absolute RGB delta was `1.88e-5` and the `t=0` to `t=3600` wrap delta was `3.94e-8` mean, `1.87e-6` max. Mode 3 selected 429 active days of 4096 (10.47%), with no consecutive active pairs and rolls within `[0,1)`. The simplified billowing curtain appearance was reviewed and accepted in the live shader by the project lead (`work/aurora-billows-final.png`). Numeric checks support continuity and finite output, not aesthetic quality.
