# Distant Horizons background work audit, 2026-09-24

Read-only inspection of the installed DH 3.3.2 jar (SHA256 `FB55DAD58BD96C03B8A164F8D141107E59B95BC46CD919CFD83438B81C3D812F`) and ShaderBench config found no safe, reversible **per-dimension** public API control for background generation. Generation plan, generation enablement, thread count, and thread runtime ratio map to global settings, while the latest singleplayer log created separate Overworld, End, and Nether generation queues. A Nether-triggered global disable can stop all loaded dimensions' queues; queue closure joins async work and can itself pause. Do not ship that as a visually neutral Nether optimization.

The saved `generationMaxChunkRadius=0` imposes no independent radius bound in DH's `WorldGenUtil.isPosInWorldGenRange()`. `surfaceRegenMaxDistancePercent=-1` makes the second `CHUNKS` pass unbounded. Server `maxGenerationRequestDistance=4096` is a separate chunk-distance request gate, not the LOD render radius. `generationRequestRateLimit=20` requests/s and eight configured generation threads yield a **per-provider** maximum retrieval queue count of 160. Prior JFR evidence saw eight World Gen and eight Render Loader threads active at a Nether view even when vanilla `chunks=true`; this does not prove they caused the whole-desktop stalls. The pre-generated dimension databases' sizes do not establish spatial coverage.

For causal diagnosis, keep Nether render radius at 64 and compare global API generation plan `SURFACE_THEN_CHUNKS` → transient `DISABLED` → restored in a guarded, fixed-pose A/B/A. Record queue closure/reopen, JFR DH worker CPU and GC, Java/system commit, process GPU allocation, and display-on PresentMon GPU Busy, CPU Busy, and present p95/p99/max. Inspect both existing LODs and newly explored terrain. The disabled arm is diagnostic only until moving-view coverage is proven.

A less disruptive candidate is an opt-in 8 → 4 → 8 generation-thread budget while Nether is active. This is still a global worker setting; each provider's retrieval queue cap would fall 160 → 80 and new LODs may load more slowly. Test moving-camera fill and transitions before considering it for play. No live setting was changed in this audit.

For a later render-radius hillclimb, 48 chunks gives 768 blocks, 248 beyond the Nether smog's 520-block cap and above the roughly 724-block diagonal of vanilla render distance 32. Forty chunks gives 640 blocks and falls inside that diagonal. Neither radius inherits the 64-chunk visual finding; test 48 first with full-resolution movement and multiple Nether biomes.
